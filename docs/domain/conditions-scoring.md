# Оценка погодных и морских условий

Модуль рассчитывает два независимых показателя от 0 до 100. Он не формирует
итоговую рекомендацию и не учитывает дорогу или предпочтения пользователя.

## Морские условия

- высота волны — 40%;
- скорость ветра — 30%;
- температура воды — 20%;
- порывы ветра — 10%.

## Погодный комфорт

- температура воздуха — 40%;
- вероятность осадков — 30%;
- количество осадков — 20%;
- облачность — 10%.

Каждый показатель преобразуется в балл плавной кусочно-линейной кривой. Пороги
хранятся отдельно в `scoring.config.ts`, поэтому изменение формулы не требует
переписывать агрегатор.

Если параметр отсутствует, модуль не подставляет значение. Итог рассчитывается
по доступным факторам, а `coveragePercent` показывает долю исходных весов,
которые были подтверждены данными. При полном отсутствии данных итоговый балл
равен `null`.
