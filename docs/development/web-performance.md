# Производительность веб-приложения

Интерактивная карта загружается динамически и начинает инициализироваться только
при приближении к области просмотра. Стили Leaflet входят в тот же отложенный
ресурс и не загружаются на страницах без карты.

Изображения обслуживаются через `next/image`. Значения `sizes` соответствуют
реальной ширине карточек и главных изображений, чтобы браузер не выбирал файл
больше необходимого. Карточки за пределами экрана используют `content-visibility`
и не требуют немедленной отрисовки длинного каталога.

## Бюджет сборки

После production-сборки бюджет проверяется командой:

```powershell
npm run check:performance
```

Пороговые значения находятся в `config/web-performance-budget.json`. Проверяются
общий объём сгенерированных JS- и CSS-чанков и размер самого крупного файла.
Команда `npm run check` выполняет эту проверку автоматически после сборки, поэтому
те же ограничения действуют в GitHub Actions.

Общий размер чанков не равен объёму первоначальной загрузки отдельной страницы:
Next.js разделяет их по маршрутам и загружает по необходимости. Бюджет служит
защитой от резкого роста всей клиентской сборки; фактические показатели страниц
перед публикацией дополнительно проверяются в браузере.
