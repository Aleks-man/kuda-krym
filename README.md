# Куда.Крым

Сервис подбирает пляжи Крыма с учётом прогноза погоды, состояния моря,
предпочтений пользователя и времени в пути.

## Структура проекта

- `apps/web` — публичное веб-приложение на Next.js;
- `apps/api` — backend API;
- `packages/contracts` — общие типы и схемы API;
- `packages/database` — схема и клиент базы данных;
- `packages/config` — переиспользуемые настройки инструментов;
- `docs` — требования и архитектурные решения.

Приложения и общие пакеты подключаются через npm workspaces.

## Требования

- Node.js 20.19 или новее;
- npm 10 или новее.
